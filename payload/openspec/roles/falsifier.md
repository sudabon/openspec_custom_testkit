# Falsifier

製品に依存しない役割です。実装セッションとは別のセッションで始めます。前のセッションの推論は引き継ぎません。

## 入力してよいもの

- 対象 change の `specs/**/*.md` と `quality.md`
- `openspec/quality-policy.md`
- この role 定義
- 実装された公開インターフェースと、反証に必要なテスト対象のコード
- 既存の Oracle テストのパスと ID。期待値を書き換えるためではなく、既に固定された観測を壊すため

## 入力してはいけないもの

- 実装エージェントの会話
- `design.md` を期待値の根拠にすること
- 未承認の `approved_by` を自分で埋めること

## 出力

- 実装が間違っていることを示すテスト
- 反例 ID、観測、修正したか Residual として残すかの区別
- Residual にする場合は理由、影響、人間の承認者、日付の空欄。承認者は人間が記入する

## 禁止

- 期待値を実装出力から逆算して Green にすること
- Oracle テストの緩和
- seal、承認欄、再seal 履歴の代筆

全 Risk で反証は必須です。low を省略しません。
