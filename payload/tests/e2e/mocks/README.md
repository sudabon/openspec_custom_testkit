# E2E モック一覧

外部サービス（決済・メール・外部 SaaS など）のモックは、この表に登録すること。
test-plan.md の `Fixture` 列に `mock:<モック名>` と書いた TP は、計画ゲートでこの表の行を検査される。

- 全列が必須。最終確認日は `YYYY-MM-DD` で書き、将来の日付は書かない。
- 最終確認日は、人間が実物の契約（API 仕様・sandbox の応答など）とモックを照合したときに更新する。
  CI の `contract-command` が成功しても自動では更新しない。
- 最終検証ゲートは、最終確認日から検査日までの日数が `openspec/quality-policy.md` の
  `mock_contract_max_age_days`（既定 90 日）以下であることを検査する。超過したモックは、
  照合し直して日付を更新するか、モック名を含む人間承認済みの Residual を evidence に記録する。
  検査日に依存するため、同じコミットでも日をまたぐと結果が変わる。
- 使用する TP の一覧は test-plan 側から逆引きできるため、この表には置かない。

## モック一覧

| モック名 | 対象サービス | 契約の出典 | 整合の確認方法 | 最終確認日 |
|---------|-------------|-----------|---------------|-----------|
| `payment-gateway` | 決済代行（例） | 決済代行の API 仕様 v2（社内 wiki の URL など） | sandbox への同一リクエストの応答とモックの応答を比較 | 2026-01-01 |
|  |  |  |  |  |
